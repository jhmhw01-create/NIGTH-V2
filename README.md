# NIGHT V2

NIGHT의 공식 웹 아카이브입니다.
기존 NIGHT 콘텐츠와 이후 개편 내용을 하나의 멀티페이지 사이트로 통합하며, 기존 페이지 주소와 아카이브 콘텐츠를 최대한 보존한 상태에서 React 기반 공통 구조로 관리합니다.

Repository: https://github.com/jhmhw01-create/NIGTH-V2

## 현재 구조

- 전체 64개 정식 라우트의 본문·메뉴·푸터를 React로 미리 렌더링하고 브라우저에서 연결합니다.
- React SPA가 아니라 기존 개별 페이지 주소를 유지하는 멀티페이지 방식입니다.
- 레거시 TAEHOON 주소 `member-taehun.html` 리다이렉트 1개를 포함해 실제 배포 HTML은 65개입니다.
- ARCHIVE 검색 카탈로그는 64개 정식 라우트와 DISCOGRAPHY의 16개 앨범 앵커를 합친 80개 기록으로 구성됩니다.
- 멤버 얼굴·헤어·구도와 기존 콘텐츠 이미지는 변경하지 않으며, 웹 전달용 미디어는 내용 변경 없이 인코딩 형식과 용량을 최적화할 수 있습니다.
- `dist`는 생성 결과물이며 Git 관리에서 제외합니다. 배포 시 소스에서 새로 빌드합니다.

## 실행

Node.js 22 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm ci
npm run build
npm test
npm run preview
```

브라우저에서 `http://localhost:4173`을 엽니다. 종료는 `Ctrl+C`입니다.

## 주요 명령

```sh
npm run build
npm test
npm run audit:media
npm run audit:media:update
npm run preview
```

- `build`: 전체 페이지 생성 및 사이트 검증
- `test`: 자동 테스트 실행
- `audit:media`: 현재 웹 미디어 검증
- `audit:media:update`: 미디어 검증 기준 갱신
- `preview`: 로컬 미리보기 서버 실행

## 폴더

- `src/pages`: 페이지별 소스와 구성
- `src/data`: 앨범·공지·팬클럽·갤러리·CONTENTS 데이터
- `src/components`: 공통 레이아웃과 화면 구성
- `public/assets`: 웹 배포용 이미지·음원·스타일·스크립트
- `scripts`: 빌드·감사·정규화·미리보기 도구
- `tests`: 자동 검증
- `dist`: 빌드 후 생성되는 실제 웹사이트
- `maintenance/original-media-manifest.json`: 저장소 외부 원본 아카이브와 대조할 변환 원본 기록
- `maintenance/media-conversions.json`: 원본과 배포용 미디어의 변환 대응 기록
- `maintenance/web-media-manifest.json`: 현재 배포 미디어 크기 및 SHA-256 검증 기록

## 콘텐츠 관리 원칙

페이지별 데이터는 가능한 한 공통 스크립트에 중복 포함하지 않고 해당 페이지에 필요한 데이터만 사용합니다. 서버 렌더링과 브라우저 연결은 같은 페이지 데이터를 기준으로 하며, 기존 주소와 미리 렌더링된 본문을 유지합니다.

기존 NIGHT 기록은 임의로 새 설정이나 날짜를 만들지 않습니다. 앨범·공지·팬클럽·갤러리·인터뷰·공연·멤버 프로필 등은 각 원본 데이터와 현재 확정 설정을 기준으로 관리합니다.

이미지 최적화는 얼굴·헤어·구도·콘텐츠 자체를 바꾸는 작업이 아니라 웹 전달용 파일의 인코딩과 용량을 조정하는 작업으로 제한합니다. 원본 추적 정보는 `maintenance`의 매니페스트에 보존합니다.

## 주요 영역

### HOME

HOME은 NIGHT의 현재 공식 아카이브 진입점입니다. 공통 내비게이션, 주요 콘텐츠 연결, 검색 진입을 제공하며 앨범 정보를 불필요하게 중복 표시하지 않습니다.

### MEMBER

DOHA · WOOHYUN · JIWOO · IHWAN · TAEHOON의 개별 프로필 페이지를 유지합니다. 공통 레이아웃과 반응형 구조를 공유하면서 각 멤버의 이미지·색상 정체성과 최신 확정 프로필 내용을 보존합니다.

### DISCOGRAPHY

현재 DISCOGRAPHY 데이터의 16개 앨범 기록을 발매 순서와 앨범 앵커로 제공합니다. 앨범별 상세 아카이브가 있는 경우 기존 주소를 유지하며 연결합니다.

### ARCHIVE / CONTENTS

ARCHIVE 검색은 현재 정식 라우트와 DISCOGRAPHY 앨범 앵커를 대상으로 합니다. 검색·분류·정렬·더 보기·검색 조건 URL과 JavaScript 미사용 시의 기본 링크를 유지합니다.

DEBUT ARCHIVE, OUT OF FRAME, SOCIAL ARCHIVE, PRESS, FIVE VOICES, WITH LUNA, IF NIGHT, VLOG, NIGHT ORIGINALS, BEHIND, TRAVEL, OBSERVATION 등 기존 기록형 콘텐츠는 각 원본 페이지의 문구·이미지·주소와 상호작용을 보존하는 방향으로 관리합니다.

### FAN / EVENT / PERFORMANCE

팬클럽, 시즌그리팅, 이벤트, 콘서트·팬미팅·스페셜 무대·시상식 기록은 기존 기록과 페이지 주소를 유지합니다. 사진 확대 UI가 있는 페이지는 닫기, 이전/다음, 키보드 이동, 포커스 복원 등 기존 접근 동작을 유지합니다.

### LISTEN / MEDIA

브라우저 기본 음원 플레이어를 사용하는 페이지는 자동재생하지 않습니다. 로딩 실패 시 재시도 안내를 제공하며, 다른 음원 재생 시 기존 재생 상태가 충돌하지 않도록 관리합니다. 실제 음원 제공 여부는 현재 보유한 배포 파일을 기준으로 합니다.

### STORE

STORE는 NIGHT 세계관의 가상 MD 아카이브입니다. 기존 상품 데이터, 옵션, 장바구니 상태 복원 구조를 유지하지만 실제 구매·결제 기능은 제공하지 않습니다.

## 접근성 및 안정성

- 페이지 본문은 스크롤 효과나 JavaScript 상태와 관계없이 기본적으로 접근할 수 있도록 구성합니다.
- 본문 바로가기와 공통 키보드 포커스 표시를 제공합니다.
- `prefers-reduced-motion` 등 모션 줄이기 설정을 고려합니다.
- React 렌더링 오류 안내를 제공하되, 오류 경계가 모든 네트워크·이벤트 오류를 대신 처리하는 것으로 간주하지 않습니다.
- 동적 사진 확대 UI는 가능한 경우 키보드 이동과 닫기 후 포커스 복원을 유지합니다.

## 빌드 검증

전체 빌드에서는 다음 항목을 자동 검사합니다.

- 정식 라우트 중복 및 잘못된 라우트 이름
- 로컬 페이지 링크
- 이미지·음원 등 로컬 미디어 대상
- 상세 페이지 앵커
- 중복 ID
- 레거시 CSS/JS 자산 참조

빌드 과정은 `scripts/build.mjs`에서 페이지를 생성한 뒤 사이트 감사와 레거시 자산 감사를 수행합니다. 원본 자산이 없는 오버레이 빌드에서는 해당 조건에 맞는 안내를 출력합니다.

자동 검증이 통과해도 실제 브라우저에서의 레이아웃, 반응형 표시, 음원 재생, 외부 링크 상태와 체감 성능까지 보장하는 것은 아닙니다. 이 항목들은 별도 브라우저 검수가 필요합니다.
