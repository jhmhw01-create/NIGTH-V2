# NIGHT 아카이브 정리

원본 NIGHT.Zip을 기준으로 작성한 추가 패치입니다.
원본 파일과 이미지, 음원은 별도로 보관하세요.

## 적용
ZIP 내용을 기존 홈페이지 루트에 덮어씁니다. archive.html이 새 통합 탐색 페이지입니다.
기존 상세 페이지 51개의 공통 메뉴에 ARCHIVE 링크만 추가했습니다.
이미지와 음원 파일은 이 패치에 포함하지 않습니다. 원본 assets를 유지해야 합니다.
배포나 GitHub 업로드는 수행하지 않았습니다.

## 관리
assets/data/archive-catalog.js: 제목·분류·요약·링크·검색 텍스트 목록.
새 기록은 이 데이터 목록에 추가할 수 있습니다. 실제 상세 페이지도 필요합니다.
기존 상세 페이지는 아직 HTML입니다. 이 작업은 완전한 프레임워크 전환이 아닌 데이터 기반 탐색 1단계입니다.
검색은 본문 텍스트도 검사하지만, 결과는 해당 페이지 또는 앨범 항목으로 연결합니다.
날짜가 확정되지 않은 콘텐츠를 임의로 연도 분류하지 않습니다.

0바이트 여행 확대용 파일 4개가 있습니다. 정상 썸네일과 기존 오류 시 대체 표시 기능은 확인했지만 원본 해상도를 복원하지는 않았습니다.
파일 삭제·이동·이름 변경·재인코딩은 수행하지 않았습니다.
미참조 표시는 삭제 허가가 아닙니다. JavaScript의 경로 조합과 full/thumbs 규칙을 먼저 확인하세요.
폴더별 파일 목록과 SHA-256 중복 정보는 image-audit.json에서 확인합니다.
얼굴·헤어·이미지 원본은 그대로 유지합니다.
